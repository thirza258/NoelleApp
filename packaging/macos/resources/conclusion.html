Noelle is installed

The Noelle Setup Assistant is opening now. It walks you through:

  1. Your Hugging Face token (optional)
  2. A hardware check
  3. Optional downloads (llama.cpp tools for GGUF, a starter chat model)

If it does not appear, open Noelle from Applications — the assistant starts on first launch. You can run it again any time from Settings › About.

To uninstall, move Noelle.app to the Trash. Your data lives in ~/.noelle and downloaded models in ~/.cache/huggingface.
